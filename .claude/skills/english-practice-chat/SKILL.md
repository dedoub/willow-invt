# English Practice (대화형)

- `/english` 페이지와 같은 데이터·기준으로 진행한다. 웹 UI만 대체하는 것이라 통계가 갈라지면 안 된다.
- 문제는 지어내지 않고 Supabase `axcfvieqsaphhvbkyzzv`의 `english_practice_items`에서만 뽑는다.
- 채점한 문항은 예외 없이 `english_practice_attempts`에 즉시 INSERT한다.
- 답을 받기 전에는 `reference_english`를 보여주지 않는다. 영어 힌트도 흘리지 않는다.
- 한 번에 한 문항만 낸다. 답이 오면 채점 → 기록 → 결과 표시 → 다음 문항.
- 출제는 `topic`, `korean_full`, `korean_chunks` 목록을 함께 보여준다.
- 프로필은 "류하"가 언급되면 `ryuha`(영국식 구어체), 아니면 `ceo`(미국식 비즈니스 구어체)다.
- 라운드는 10문항이고 신규 6 + 복습 4다. 복습 대상은 마지막 시도가 불합격인 문항이다.
- 배점은 의미 50 / 문법 30 / 자연스러움 20이고 80점 이상 합격이다.
- `reference_english`는 정답이 아니라 하나의 가능한 답이다. 표현이 달라도 의미가 맞고 자연스러우면 감점하지 않는다.
- 채점은 대화 중인 모델이 직접 한다. 페이지의 llm-json 프록시를 호출하지 않는다.
- 신규 풀이 비면 손으로 짓지 말고 `POST /api/english/generate`로 채운다. ceo 배치는 업무 4 + 기본 비즈니스 회화 3 + 미국 일상 표현 3으로 섞인다.
- 한글 청크는 영어 어순을 따르되 각 청크가 혼자서도 말이 되어야 한다. 관형형으로 끝내거나(`앱을 소유한.`) 관형형에 요를 붙이지(`통합되는요`) 않는다.
- 시작과 마무리에 누적 통계(총 문항, 시도, 정답률, 미시도, 복습대기)를 알린다.

SQL·피드백 JSON 모양·프롬프트 기준은 `.agents/skills/english-practice-chat/SKILL.md`를 따른다.
