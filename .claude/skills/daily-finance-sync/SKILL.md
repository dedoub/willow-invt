# Daily Finance Sync

- 실행 중 인증 허가를 묻지 않고 회사별 Keychain 자격증명을 사용한다.
- 텐소프트웍스 필수 소스: 홈택스, 우리은행, 신한은행, 우리카드, 위택스, 사회보험이다.
- 윌로우 필수 소스: 홈택스, 신한은행, KB카드, 위택스, 사회보험이다.
- 홈택스는 세금계산서와 국세·부가세 고지, 위택스는 지방세, 사회보험은 건강보험·연금·고용·산재 고지를 수집한다.
- 완료 순서는 `수집 → 검증 → DB UPSERT → 분류 → 지급 매칭`이다.
- 국세는 홈택스가 23:30~06:59 납부할세액 화면을 닫아 두므로 새벽 배치에 넣지 않고 07시 별도 잡으로 돈다.
- 묶음 하나만 다시 돌릴 때는 `scripts/run-local-finance.sh <회사> --only <묶음>`을 쓴다.
- 고지는 `finance_tax_obligations`에 저장하고 기존 은행 출금과 연결한다. 별도 expense를 생성하지 않는다.
- 동일 금액 후보가 여러 개면 자동 매칭하지 않고 미지급으로 남긴다.
- 일부 소스 실패를 숨기지 않고 회사·소스·단계·재시도 결과를 알린다.

검증 명령은 `.agents/skills/daily-finance-sync/SKILL.md`를 따른다.
