# 텐소프트웍스 경영지원 업무 (김의향 이사 인수인계)

원문: 텐소 메일 「급여, 지원금 신청 포함 재무관련 업무 인수인계」(2026-09-10), 「인수인계 서류 2」(2026-10-01)의 첨부 매뉴얼.
정리본: 업무위키 tensw-mgmt 「김의향 이사 업무 인수인계 정리 (2026-10-01)」.

**원문 매뉴얼에 사이트 비밀번호와 직원 개인정보가 평문으로 있다. 여기·위키·로그·메일로 옮기지 않는다.**
비밀번호는 Keychain 에 두고 이름만 적는다. 원문 첨부는 메일에서 바로 연다.

## 일하는 방식

경영관리 에이전트(`mgmt-agent`)가 일정 원장으로 돌린다. 업무마다 세 칸으로 나눈다.

- **에이전트**: 기한 감시, 서류 목록 대조, 발급 가능한 증명서 수집(홈택스·4대보험·인터넷등기소), 신청서·메일 초안.
- **대표 결정**: 결제, 기관 제출, 서명·인감, 담당자 지정. 윌리 결정함 버튼으로 온다.
- **사람만**: 현장 방문(은행 창구), 전화 응대, 실사 동석, 손 서명.

발송·제출·결제는 모두 초안까지만 만든다(`feedback_willy_dispatch_control`). 기관 사이트 로그인은 인증서 규칙을 따른다.
인증서 줄은 소유자 이름으로 고르고, 비밀번호는 한 번만 넣는다. 거부되면 멈춘다.

자동화 단계: ① 일정·알림만 → ② 서류 수집 레시피 → ③ 신청서 초안까지. 아래 「단계」가 지금 위치다.

## 1. 기업부설연구소 (KOITA)

- **과거**: 2026-02-02 설립. 2026-03-11 KOITA 보완요청 뒤 인정. 전담연구원 조성민·전희나(발령 2026-02-10). 벤처 부설이라 전담 2명으로 된다.
  연구소 안에 서류철(사업자등록증·임대차계약서·학위·인사발령·변경신고)을 비치했다. 연구노트는 매월 1장 이상 쓴다.
- **에이전트**:
  - 매월 말: 두 연구원에게 연구노트 작성 확인 메일 초안을 만든다.
  - 인력 변동 때(4대보험 취득·상실, 겸직): 변경신고가 필요하다고 결정함에 올린다.
- **대표**: 실사 때 동석(연구소장 또는 관리담당). 도면·공간이 바뀌면 변경신고를 승인한다.
- **덫**:
  - 실사는 불시에 올 수 있다. 창고처럼 쓰거나 기자재 전선이 빠져 있으면 바로 부적격이다.
  - 미조치하면 직권취소되고 세액공제가 추징된다.
- **단계**: ①

## 2. 강남구 인턴십 지원금

이미 레시피가 있다(`tensw-internship-subsidy-application`, `gangnam-attendance-sheets`). 인수인계에서 더할 것만 적는다.

- 실사 때 인턴이 자기 자리에서 근무하고 있어야 한다. 인터뷰와 설문을 받는다.
- 고용보험 5인 이상 판단에서 김정한(대표 직계)은 빠진다.
- 담당 메일은 2026-09-11부터 `admin@tensoftworks.com` 으로 바뀌었다.

    전년 매입매출처별 세금계산서합계표, 전년 원천징수이행상황신고서, 최근 주주명부, 법인등기부, 대표 신분증 사본.
  - 대출 연장(매뉴얼): 서류 6종을 이메일로 보낸다(사업자등록증, 부가세과세표준증명, 주주명부, 법인등기부, 법인인감증명서, 국세완납증명).
    은행 창구에는 같은 서류와 법인 인감·명판을 가져간다. 대리인이면 인감을 찍은 위임장과 신분증 원본도 가져간다.
- **대출 만기**: 운전자금 1.5억 2027-02-26 · 1.17억 2027-05-12 · 2억 2027-05-12. SBI에도 2건이 있다(만기 확인 필요).
- **에이전트**:
  - 홈택스: 부가세과세표준증명, 납세증명, 원천징수이행상황 내려받기. 같은 홈택스 세션(`hometax-session.mjs`)을 쓴다.
  - 인터넷등기소: 등기부 열람·발급(유료 결제는 결정함).
  - 주주명부는 법인 서류함(`npm run corp`)에서 만든다.
  - 재무제표확인원은 세무법인형운에 요청 메일 초안을 만든다.
  - 서류가 다 모이면 지점 담당 회신 초안에 첨부한다.
- **대표**: 개인신용정보조회 신청서 서명, 신분증 사본, 창구 방문(또는 위임장 인감).
- **단계**: ① (만기 60일 전·3월 신용평가 일정만). 다음은 증명서 일괄 수집 레시피.
