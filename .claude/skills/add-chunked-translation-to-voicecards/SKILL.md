# 한글 청킹 번역을 VoiceCards 시트에 추가

## 기본 대상

- 영어 덱 스프레드시트 ID: `1igjdCEgPeKDzcuYiDvHyct3bmE4KplsmJROwhvisrcs`
- 영어 덱 시트 GID: `1079541785`
- 영어 덱 열 순서: `Question`, `Answer`, `Memo`, `Bookmark`
- 영어 덱은 `Question`에 한글 청크, `Answer`에 대응하는 영어 청크를 넣는다.
- 독일어 덱 스프레드시트 ID: `12Rj0jP3ei_eh01pMr2f0n29uYpadaFShqarglIWqbQ0`
- 독일어 덱 기본 탭: `Voice Cards`
- 독일어 덱 열 순서: `Question`, `Answer`, `Memo`, `Favorite`
- 독일어 덱은 `Question`에 한글 청크, `Answer`에 같은 호흡과 의미의 자연스러운 독일어 청크를 넣는다.
- `Memo`, `Bookmark`, `Favorite`은 별도 요청이 없으면 비워 둔다.

사용자가 특정 시트 링크나 언어를 명시하면 그 지시를 우선한다. 별도 지정이 없고 "청킹번역 넣어줘"라고만 하면 영어 덱과 독일어 덱을 모두 갱신한다.

## 인증과 쓰기 경로

- 기본 쓰기 경로는 WILLOW-INVT의 `.env.local`에 있는 `GOOGLE_SA_JSON_B64` 서비스 계정이다.
- 서비스 계정 JSON은 로그나 응답에 출력하지 않고 메모리에서만 디코딩한다.
- `googleapis`의 JWT 클라이언트와 `https://www.googleapis.com/auth/spreadsheets` 범위를 사용한다.
- 대상 탭 제목은 `spreadsheets.get`으로 `gid`와 일치하는 탭을 찾아 사용한다. 기본 탭은 `Voice Cards`다.
- 추가는 `spreadsheets.values.append`와 `insertDataOption=INSERT_ROWS`, `valueInputOption=RAW`를 사용한다.
- 현재 서비스 계정 프로젝트에는 Google Sheets API가 활성화되어 있다. `SERVICE_DISABLED`가 다시 발생하면 임의 우회하지 말고 API 상태를 확인한다.

## 실행 절차

1. 영어 덱과 독일어 덱을 읽어 각 헤더와 기존 행을 확인한다.
2. 영어 덱 헤더가 `Question,Answer,Memo,Bookmark`, 독일어 덱 헤더가 `Question,Answer,Memo,Favorite`와 다르면 해당 시트에는 쓰지 말고 실제 구조를 보고한다.
3. 한글의 문장 구조를 보존하지 말고 의도, 감정, 논리 흐름을 먼저 파악한다.
4. 전체 내용을 뉴욕 비즈니스 현장에서 자연스러운 미국 영어의 의식 흐름으로 다시 쓴다.
5. 재작성한 문장에서 반복 연습할 가치가 있는 문장 프레임을 추출한다.
6. 각 프레임은 원문에 맞춘 기본 표현 1개와 같은 구조의 변형 2개, 총 3개로 만든다.
7. 각 영어 문장을 아래 청킹 규칙에 따라 실제 발화 단위로 나누고, 같은 위치의 자연스러운 한글 뜻을 붙인다.
8. 독일어는 영어 번역문이나 기존 독일어 답변을 재사용하지 않고 한글 원문의 의도에서 독립적으로 다시 쓴다. 독일어 전체 문장을 먼저 자연스럽게 완성한 뒤 실제 독일어 발화 단위로 나누고, 각 독일어 청크의 의미에 맞는 한글 질문을 별도로 붙인다.
9. 각 시트에서 `Question + Answer`가 같은 행은 제외한다.
10. 위 서비스 계정으로 Google Sheets API에 연결해 두 시트의 마지막 데이터 행 아래에 각각 추가한다. 서비스 계정이 실패할 때만 로그인된 브라우저를 폴백으로 사용한다.
11. 두 시트를 다시 읽어 추가된 행 수와 마지막 행의 실제 값을 각각 검증한다.
12. 두 시트 모두 검증된 경우에만 전체 완료라고 보고한다. 한쪽이라도 쓰기 권한이나 인증이 없으면 성공한 시트와 실패한 시트를 구분해 보고한다.

## 영어 재작성 스타일

- 한글 어순이나 접속 구조를 그대로 옮기지 않는다.
- 화자가 실제로 전달하려는 판단과 감정의 결을 먼저 잡고 미국 영어의 사고 순서로 다시 구성한다.
- 기본 톤은 뉴욕 비즈니스 대화에 어울리는 `clear`, `polished`, `direct`, `confident`다.
- 번역문처럼 보이는 문어체보다 실제 회의, 네트워킹, 인터뷰에서 입으로 말할 수 있는 영어를 우선한다.
- 필요하면 `I mean`, `But the truth is`, `From the outside`, `It is more like` 같은 자연스러운 담화 표지를 사용한다.
- 원문의 뉘앙스를 과장하거나 화자의 입장에 없는 공격성, 확신, 감정을 추가하지 않는다.

## 프레임 변형 규칙

- 반복 가능한 프레임은 특정 인물이나 사건을 바꿔도 재사용할 수 있는 문장 골격이어야 한다.
- 프레임 하나마다 반드시 3개 표현을 만든다: 기본 표현 1개 + 구조를 유지한 변형 2개.
- 세 표현은 단어만 기계적으로 치환하지 말고 같은 사고 기능을 수행하는 자연스러운 대안이어야 한다.
- 고유명사와 구체적 사실을 연습해야 하는 경우 기본 표현에는 보존하고, 변형에서는 다른 상황에도 쓸 수 있게 일반화한다.
- 변형 간 난이도와 톤은 크게 벌리지 않는다. 같은 프레임을 반복해 입에 붙이는 것이 목적이다.

## 청킹 규칙

- 청킹은 의미 프레임을 나누는 작업이 아니라, 한 번 말할 때 입에서 나오는 실제 어절을 나누는 작업이다.
- 한글 `Question`은 대체로 3~4어절의 짧은 발화 단위를 목표로 하되, 영어·독일어 청크가 실제로 뜻하는 범위를 정확히 담는 것을 단어 수보다 우선한다.
- 영어 `Answer`는 같은 발화 단위에 대응시키되 언어 차이 때문에 3~6단어가 될 수 있다.
- 단어 수를 기계적으로 맞추기보다 실제로 말할 때 한 호흡과 억양으로 이어지는지를 우선한다.
- `But the truth is`, `he's been at this`, `for 15-plus years`처럼 호흡과 억양이 자연스럽게 끊기는 지점을 우선한다.
- 1~2단어 청크는 피하고 인접 청크에 합친다. 단, 문장 끝의 독립 발화가 자연스러운 경우만 예외로 허용한다.
- 영어가 5~6단어여도 `People might look at Garrett now`처럼 한 번에 자연스럽게 말하면 유지한다.
- 한글 문장을 먼저 임의로 자른 뒤 외국어를 끼워 맞추지 않는다. 영어와 독일어의 자연스러운 발화 청크를 먼저 확정하고, 각 청크가 실제로 뜻하는 범위에 맞춰 한글을 붙인다.
- 한글과 영어의 행 순서와 의미를 반드시 1:1로 맞춘다. 한글에만 있거나 영어에만 있는 주어·서술어·부정·추측·인과 의미가 없어야 한다.
- 독일어가 영어와 다른 어순을 요구하면 독일어 문장 전체의 자연스러움을 우선하고, 독일어 덱의 한글 질문도 해당 독일어 청크의 의미 순서에 맞춰 독립적으로 작성한다.
- 한글 `Question`은 영어 청크의 위치와 의미에 맞는 자연스러운 발화 단서로 작성한다. 문맥을 알아야만 뜻이 통하는 과도한 생략은 피한다.
- 숫자, 고유명사, 회사명은 원문 의미를 보존한다.

### 청킹 예시

```text
개럿을 지금 보면 | People might look at Garrett now
전부 하루아침에 된 것처럼 | and think it all happened overnight.
근데 사실은 | But the truth is,
그는 이 일을 계속 해왔어요 | he's been at this
15년 넘게 | for 15-plus years,
거슬러 올라가면 | going all the way back
Recon Capital 때부터 | to Recon Capital,
그다음 Mirae Asset을 거쳐 | then Mirae Asset,
```

## 품질 검증

- 모든 행에 한글 `Question`과 영어 `Answer`가 모두 있어야 한다.
- 각 행을 독립적으로 대조해 주어, 동작, 시제, 태도, 연결어가 서로 일치하는지 확인한다. 인접 행의 뜻을 미리 당겨 쓰거나 다음 행으로 미루지 않는다.
- 원문의 의미가 누락되거나 다른 행에 중복되지 않았는지 확인한다.
- 영어 청크를 이어 읽었을 때 원문 전체의 자연스러운 영어 문장이 되어야 한다.
- 영어 전체 문장이 한글 구조를 따라간 직역투가 아닌지 다시 읽어 확인한다.
- 각 프레임에 기본 표현을 포함해 정확히 3개 변형이 있는지 확인한다.
- 한글 청크가 대체로 3~4어절인지, 영어 청크가 같은 호흡과 의미에 자연스럽게 대응하는지 확인한다.
- 기존 행과의 중복 여부는 공백을 정리한 `Question + Answer` 기준으로 확인한다.
- 영어 덱과 독일어 덱은 같은 원문 의도와 프레임 수를 공유하되, 각 언어의 자연스러운 어순과 청크 경계가 다르면 `Question` 값과 행별 의미 순서는 달라도 된다.
- 독일어 답변이 영어 문장 구조를 따라간 번역투인지, 기존 답변을 보존한 채 한글 질문만 바꾼 것은 아닌지 별도로 검수한다.
- 기존 행을 재사용하거나 새 문장을 추가하기 전에 현재 덱의 기존 청크도 같은 기준으로 검수하고, 의미 경계가 틀린 행은 먼저 수정한다.
- 독일어 청크를 이어 읽었을 때 독일어 문장 전체의 문법과 어순이 자연스러워야 한다.
- 각 시트의 쓰기 전 예상 추가 행 수와 쓰기 후 실제 증가 행 수가 같아야 한다.

## 보고 형식

짧게 다음만 보고한다.

```text
청킹 번역 N개를 영어 덱과 독일어 덱에 각각 추가했고, 두 시트 모두 재조회 검증까지 완료했어요.
```

중복 제외가 있으면 함께 표시한다.

```text
영어 덱과 독일어 덱에 청킹 번역을 각각 추가했고, 기존 중복은 제외했어요. 두 시트 모두 재조회 검증까지 완료했어요.
```

쓰기 실패 시 완료라고 말하지 않는다.
