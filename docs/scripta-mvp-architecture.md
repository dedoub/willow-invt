# Scripta MVP Architecture

작성일: 2026-08-23

## 1. 제품 정의

Scripta는 사용자가 실제로 숙달해야 할 글을 Cortex에 저장하고, 문장부터 문단과 전체 글까지 단계적으로 재구성하도록 훈련하는 다국어 글쓰기 숙달 웹앱이다.

핵심 루프는 다음과 같다.

`목표 글 등록 -> 학습 구조 생성 -> 문장 연습 -> 문단 연습 -> 전체 글 연습 -> 취약 단위 재학습`

Scripta는 범용 문서 편집기나 자유 주제 AI 첨삭기가 아니다. 사용자가 선택한 목표 글과 그 글에서 파생된 표현, 논리, 구조를 자기 것으로 만드는 데 집중한다.

## 2. Cortex 경계

Cortex는 언어별 폴더가 아니라 하나의 쓰기 목표와 채점 기준을 공유하는 학습 컨테이너다.

같은 언어라도 목적과 문체가 다르면 Cortex를 분리한다.

- 영어 자기소개서와 영어 업무 이메일은 서로 다른 Cortex다.
- IELTS 에세이와 영어 발표문은 서로 다른 Cortex다.
- 하나의 Cortex에는 같은 목표로 숙달할 여러 글을 등록할 수 있다.

Cortex 생성 시 다음 정보를 설정한다.

- 이름과 학습 목적
- 목표 언어와 사용자 모국어
- 사용 맥락과 목표 문체
- 학습 방식: 정확 재현 또는 의미 재구성
- AI 채점 기준과 통과 점수

## 3. 콘텐츠 계층

데이터 계층은 다음과 같다.

`Cortex -> Text -> Paragraph -> Sentence -> Chunk`

- Text는 사용자가 등록한 하나의 완결된 목표 글이다.
- Paragraph는 전체 글의 논리 단위다.
- Sentence는 반복 학습과 취약도 계산의 기본 단위다.
- Chunk는 외국어 문장의 의미와 어순을 복원하는 보조 단위다.

학습 이력은 시도 단위로 저장하고, 각 단위의 현재 숙련도는 마지막 시도와 최근 반복 성과를 기준으로 계산한다.

## 4. 언어별 학습 엔진

### 외국어 Cortex

외국어 글은 목표 언어로 먼저 자연스럽게 확정한 뒤, 목표 언어의 의미 흐름과 어순에 맞춰 모국어 청크를 생성한다. 다른 언어를 중간 번역 언어로 사용하지 않는다.

연습 단계는 다음과 같다.

1. 모국어 의미 청크를 보고 목표 언어 문장을 쓴다.
2. 문단의 핵심 의미와 문장 순서를 보고 문단 전체를 쓴다.
3. 글의 개요와 문단 역할만 보고 전체 글을 쓴다.

채점 기준은 의미 보존, 문법, 자연스러움, 목표 문체다.

### 모국어 Cortex

모국어 글에는 번역 청크를 만들지 않는다. 문장에는 핵심어와 질문을, 문단에는 주장과 근거를, 전체 글에는 개요와 문단 역할을 제공한다.

채점 기준은 핵심 내용 포함, 논리적 연결, 문장 완성도, 목표 문체다.

## 5. 학습 단계와 해금

### 문장 연습

- 한 번에 한 문장을 제시한다.
- 외국어는 의미 청크를, 모국어는 핵심어 또는 질문을 단서로 사용한다.
- 80점 이상을 통과로 처리한다.
- 불합격 문장은 취약 큐로 이동한다.

### 문단 연습

- 문장 단위 숙련도가 기준에 도달하면 해금한다.
- 문단의 핵심 의미와 문장 역할만 제공한다.
- 의미 누락, 문장 순서, 연결성, 문장 품질을 채점한다.

### 전체 글 연습

- 주요 문단이 통과되면 해금한다.
- 제목, 목적, 개요만 제공하고 전체 글을 재구성하게 한다.
- 문단 구성, 문단 내 문장 구성, 개별 문장 품질로 나눠 채점한다.

### 취약 큐

- 마지막 시도가 불합격인 단위를 우선 출제한다.
- 문장 취약점이 반복되면 해당 문장이 속한 문단 연습을 다시 잠근다.
- 전체 글 채점에서 발견된 약점은 문단 또는 문장 단위로 분해해 재학습시킨다.

## 6. 기존 willow-invt MVP 재사용

### 그대로 재사용할 부분

- `PracticeView`의 한 문제씩 푸는 흐름과 모바일 반응형 입력 UI
- 타이핑과 손글씨 입력, 맥락 없는 OCR 전사 후 별도 채점하는 구조
- 80점 통과 기준과 마지막 시도 기준 취약 큐
- 신규 위주, 균형, 복습 위주 큐 구성
- 즉시 채점 결과의 최소 수정, 자연스러운 버전, 핵심 피드백
- CE 작문 채점의 문단 구성, 문단 내 문장 구성, 문장 품질 평가
- LLM JSON 프록시와 채점 결과 정규화 패턴

### Scripta에서 교체할 부분

- 고정 `ceo`, `ryuha`, `ryuha_written` 프로필을 사용자 소유 Cortex 설정으로 교체한다.
- 위키와 이메일에서 자동 생성하는 문제은행을 사용자 등록 목표 글 기반 학습 단위로 교체한다.
- `english_practice_items`의 평면 문장 구조를 Cortex, Text, Paragraph, Sentence 계층으로 확장한다.
- 영어 전용 필드를 목표 언어와 모국어를 지원하는 중립 필드로 변경한다.
- 문장 정답률만 표시하는 통계를 문장, 문단, 전체 글 숙련도로 확장한다.

## 7. MVP 화면

### Cortex 목록

- Cortex별 목표 언어, 목적, 등록 글 수를 표시한다.
- 문장, 문단, 전체 글 숙련도를 각각 표시한다.
- 오늘의 취약 단위와 이어서 연습할 위치를 바로 제공한다.

### Cortex 상세

- 등록된 글 목록과 글별 숙련도를 표시한다.
- 새 목표 글 등록과 기존 글 편집을 제공한다.
- 문장, 문단, 전체 글 연습 진입점을 제공한다.

### 목표 글 등록

- 원문을 붙여 넣거나 직접 작성한다.
- AI가 문단, 문장, 의미 청크와 연습 단서를 생성한다.
- 사용자가 생성 결과를 확인하고 수정한 뒤 학습을 시작한다.

### 연습 화면

- 기존 `PracticeView`를 공통 셸로 사용한다.
- 연습 단위에 따라 문장, 문단, 전체 글 입력 영역을 바꾼다.
- 채점 결과 아래에 현재 단위 숙련도와 다음 연습 행동을 표시한다.

## 8. 데이터 모델 초안

### scripta_cortices

- `id`, `user_id`, `name`, `purpose`
- `native_language`, `target_language`, `target_register`
- `practice_mode`, `pass_score`, `created_at`, `updated_at`

### scripta_texts

- `id`, `cortex_id`, `title`, `source_text`, `outline`
- `status`, `created_at`, `updated_at`

### scripta_units

- `id`, `text_id`, `parent_id`
- `unit_type`: paragraph, sentence, chunk
- `position`, `target_text`, `native_cue`, `learning_cue`, `metadata`

### scripta_attempts

- `id`, `user_id`, `cortex_id`, `text_id`, `unit_id`
- `practice_level`: sentence, paragraph, text
- `answer`, `score`, `passed`, `feedback`, `created_at`

텍스트 전체 연습은 `unit_id`를 비우고 `text_id`에 연결한다. 문단과 문장은 동일한 단위 테이블에서 계층으로 관리해 공통 큐와 숙련도 계산을 재사용한다.

## 9. 크레딧 경계

무료 영역은 저장된 학습 구조를 이용한 반복 연습, 정확 비교, 기존 채점 결과 조회다.

크레딧은 AI 연산이 새로 발생하는 다음 행동에 사용한다.

- 목표 글을 문단, 문장, 청크와 단서로 변환하기
- 외국어 청킹 번역 생성 또는 재생성하기
- 의미 기반 문장, 문단, 전체 글 채점하기
- 상세 첨삭과 취약 단위 재구성하기

단순 재시도와 다음 문제 이동에는 크레딧을 부과하지 않는다.

## 10. MVP 범위

첫 버전에는 다음 기능만 포함한다.

1. Cortex 생성과 목표 언어, 모국어, 목적 설정
2. 목표 글 등록과 학습 구조 자동 생성
3. 외국어 청킹 단서와 모국어 핵심어 단서
4. 문장, 문단, 전체 글 연습
5. AI 채점과 취약 큐
6. 단계별 숙련도와 이어서 연습하기

공유 Cortex, 공개 템플릿, 전이형 자유 작문, 네이티브 모바일 앱은 사용성과 잔존을 확인한 뒤 추가한다.
