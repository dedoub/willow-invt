# UI 지적 로그

CEO 가 화면을 보고 한 지적을 한 줄씩 남긴다. 일회성 대화로 사라지지 않게 하는 장부이자, 사람 개입이
줄고 있는지 재는 원본이다(`npm run ui-check -- --stats` 가 주 단위로 센다).

**지적이 나오면 그 자리에서 이 줄을 쓰고, "자산" 칸을 채운 뒤에 끝낸다.** 자산은 넷 중 하나 이상이다.

| 자산 | 어디 | 언제 |
|---|---|---|
| 규칙(코드) | `scripts/lib/ui-check-rules.mjs` | 기계로 잴 수 있는 것 |
| 사례(테스트) | `scripts/lib/ui-check-rules.test.mjs` | 모든 지적 — 재발하면 안 되므로 |
| 기준(프롬프트·SOP) | `docs/design-system/ui-judge-rubric.md`, `dashboard-system.md` 점검표 | 눈으로 판단할 것 |
| 기억 | 메모리 `feedback_card_checklist` 등 | 화면 밖 맥락(누가 무엇을 싫어하는지) |

"재발"은 같은 종류 지적이 다시 나오면 그 날짜를 적는다. 재발이 있으면 자산이 약했던 것이다.
