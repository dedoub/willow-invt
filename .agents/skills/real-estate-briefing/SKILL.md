# Real Estate Briefing

강남/서초/송파 추적 단지의 호가 vs 실거래가 괴리율 브리핑 워크플로우.

## 추적 대상

`re_complexes.is_tracked = true`인 현재 운영 단지를 조회해서 사용한다. 단지 수와 목록을 문서에 고정하지 않는다.

## 매일 자동 브리핑 범위

- **평형대**: 전체 추적 평형과 50평대를 함께 본다.
- **구**: 강남구·서초구·송파구 전체를 본다.
- **거래 유형**: 매매와 전세를 반드시 분리한다.
- **비교 기준**: 현재 괴리율, 7일 변화, 전일 보고의 수치·판단·가설을 함께 비교한다.
- **외부 맥락**: 같은 날 주요 부동산 뉴스와 한국부동산원·국토교통부 등 공식 자료를 검색한다.

## Step 1: 데이터 조회

### MCP 도구 사용 순서

1. **`re_get_listing_gap`** — 핵심 도구. 호가 vs 실거래가 괴리율
   - `trade_type`: "매매" (기본) / "전세"
   - 반환값: 단지별, 평형대별 실거래 평당가, 최저호가 평당가, 괴리율, 매물수

2. **`re_list_listings`** — 실제 호가 레인지 확인 (보조)
   - `complex_name`: 단지명
   - `trade_type`: "매매"
   - `limit`: 10~20
   - 반환값: 개별 매물의 호가, 면적, 층, 방향

3. **`re_get_summary`** — 전체 시장 요약 (선택)
   - `district`: 구 필터
   - 반환값: 추적단지수, 평균 평당가, 평균 괴리율

## Step 2: 단위 규칙 (필수!)

### 평당가 표기
- **억/평 단위 사용**: `1.22억/평`, `0.92억/평`
- DB 원본은 만원 단위 (예: 12,249만) → `1.22억`으로 변환
- ❌ 절대 금지: `12,249만/평` — CEO에게 직관적이지 않음

### 총 호가 표기
- **억원 단위 사용**: `36.9억`, `45.2억`
- 계산: 평당가(억) × 평수 = 총 호가(억)
- 예: 1.08억/평 × 34평 = 36.7억
- ❌ 절대 금지: 10으로 나누는 실수 (4.17억 → 틀림, 41.7억이 맞음)

### 변환 공식
```
DB 평당가(만원) → 억 표기: 값 / 10,000 → "X.XX억/평"
총 호가(억): 평당가(억) × 평수
평수: 공급면적(㎡) / 3.3058
```

## Step 3: 매일 브리핑 포맷

자동 생성된 숫자 요약은 분석 재료일 뿐 최종 보고서가 아니다. 아래 순서를 지킨다.

1. **핵심 판단**: 오늘 시장 국면을 한 문장으로 정의한다.
2. **어제 판단 대비 변화**: 전일 가설이 강화됐는지, 약화됐는지, 반박됐는지 밝힌다.
3. **매매**: 전체와 50평대의 현재 괴리율·7일 변화·표본을 해석한다.
4. **전세**: 전체와 50평대의 현재 괴리율·7일 변화·표본을 해석한다.
5. **뉴스·공식 통계 교차검증**: 외부 주장을 내부 데이터가 확인하는지 반박하는지 구분하고 원문 URL을 붙인다.
6. **원인 가설과 다음 확인 신호**: 매물, 실거래, 전세, 지역 확산 여부 중 무엇을 다음에 확인할지 적는다.
7. **데이터 신뢰도**: 신규 거래가 적거나 표본이 얇으면 결론의 강도를 낮춘다.

단순히 `매매 약세·전세 보합`으로 끝내지 않는다. 전일 보고를 읽지 않았거나 뉴스 URL이 없으면 완성된 일일 보고서로 발송하지 않는다.

### 상세 조회 요청 포맷

### 구별로 섹션 분리 (CEO 요청한 구만)

```
## 🏠 [구이름] [평형대] — [한 줄 요약]

| 단지 | 실거래 평당가 | 최저호가 평당가 | 괴리율 | 매물수 |
|------|------------|-------------|-------|-------|
| 래미안대치팰리스 | **1.22억**/평 | **1.08억**/평 | **-11.5%** | 301건 |
| ... | ... | ... | ... | ... |

**추정 총 호가 (최저~최고):**
- **래미안대치팰리스** 34평 기준: 약 36.9억 ~ 52.5억
- ...

**[평형대] 요약**: [매수자/매도자 우위 판단 + 핵심 포인트]
```

### 한 줄 요약 패턴
- 전 단지 호가 < 실거래가 → "매수자 우위"
- 전 단지 호가 > 실거래가 → "매도자 우위"
- 혼재 → "단지별 차별화"

### 괴리율 해석
| 괴리율 | 의미 |
|--------|------|
| -10% 이상 | 매도 압력 매우 강함 |
| -5% ~ -10% | 매도 압력 있음 |
| -3% ~ -5% | 약한 약세 |
| -3% ~ +3% | 균형 |
| +3% ~ +5% | 약한 강세 |
| +5% ~ +10% | 매수 경쟁 |
| +10% 이상 | 과열 |

## Step 4: 종합 판단

브리핑 마지막에 종합 판단 추가:
- 전체 시장 방향성 (약세/강세/혼조)
- 평형대별 차이 (대형 vs 소형)
- 매물 물량 수준 (풍부/적정/부족)
- 매수/매도 시사점

## 멀티 메시지 분할

텔레그램 브리핑 시 `---SPLIT---` 사용:
- 구별로 분할 (강남 → SPLIT → 서초 → SPLIT → 송파)
- 평형대별로 분할 (30평대 → SPLIT → 40평대)
- 종합 판단은 마지막 SPLIT 후

## 데이터 없는 경우

특정 평형대/단지에 데이터가 없으면:
- "유의미한 거래 데이터 없음" 표기
- 해당 행 생략 (빈 칸으로 채우지 않음)
- 40평대 이상은 데이터 부족 가능성 높음 — 미리 안내

## CEO 브리핑 규칙 참조

- AGENTS.md `real_estate_monitoring` 섹션 준수
- 매일 자동 보고는 전체와 50평대, 매매와 전세를 모두 포함한다.
- 전일 판단과 오늘 데이터를 연결해 시장 국면의 연속성을 추적한다.
- 상세 단지별 데이터는 CEO 요청 시에만
